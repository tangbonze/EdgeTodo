侧边待办 · EdgeTodo
A todo list that lives on your screen edge
──────────────────────────────────────────────

【中文】

安装
  把左边的 EdgeTodo 拖到右边的「应用程序」文件夹里即可。
  首次打开若提示「无法验证开发者」：右键点图标 → 打开 → 再点「打开」。

用法
  · 鼠标滑到屏幕边缘的灰色小拉手，面板弹出；移开自动收起
  · 点窗口空白处直接打字，回车建成待办
  · 标题里写时间会自动解析，例如「明天 9:00 交报价单」
  · ⌥⌘T 显示 / 隐藏面板
  · 右键条目：设置提醒、移动列表、删除
  · 右键灰色拉手：切换左右边缘、选择显示在哪块屏幕
  · 菜单栏图标：开机自启、切换界面语言（跟随系统 / 中文 / English）

多显示器
  · 每块屏幕都可以有一条拉手（右键拉手 → 显示在）
  · 在哪块屏幕唤起，面板就出现在哪块屏幕
  · 每块屏幕的拉手位置分别记忆

数据与权限
  待办直接存在系统「提醒事项」里，随 iCloud 同步；
  没有账号、不上传、不联网。
  需要「提醒事项」和「语音识别」权限，首次使用会弹窗询问。

系统要求
  macOS 13 及以上（Apple Silicon）

【English】

Install
  Drag EdgeTodo on the left into the Applications folder on the right.
  If macOS says the developer cannot be verified on first launch:
  right-click the icon → Open → Open again.

Usage
  · Hover the small grey handle at the screen edge and the panel slides out;
    it hides again when the mouse leaves
  · Click any blank spot in the panel and type; press Return to create the todo
  · Put a time in the title and it is parsed automatically, for example
    「明天 9:00 交报价单」 (natural-language parsing is Chinese-only for now)
  · ⌥⌘T shows / hides the panel
  · Right-click an item: set reminder, move to another list, delete
  · Right-click the grey handle: dock to the left or right edge,
    or choose which display shows it
  · Menu bar icon: launch at login, switch the interface language
    (Follow System / 中文 / English)

Multiple displays
  · Every display can have its own handle (right-click a handle → Shown On)
  · The panel appears on whichever display you trigger it from
  · Each display remembers its own handle position

Data and permissions
  Todos live in macOS Reminders and sync via iCloud.
  No account, no uploads, no network requests.
  Reminders and Speech Recognition permissions are requested on first use.

Requires macOS 13 or later (Apple Silicon)
